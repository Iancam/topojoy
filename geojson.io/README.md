# geojson.io

Taken from [geojson.io](https://geojson.io/) or [github.com/mapbox/geojson.io](https://github.com/mapbox/geojson.io). These are no longer being updated.

I've updated the repo to work with vite instead of rollup. The production build is in the root directory.

`npm run build` only outputs a `tailwind_dist.css` file.

to run dev, cd into the root directory and run `npm run dev` or `npx vite`
